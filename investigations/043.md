## למה זה קרה (Root Cause)

### הכשל המבני: אסימטריה של N מפעילים מול stopper יחיד

| | מי מפעיל typing | מי עוצר typing |
|---|---|---|
| אירועים | `UserPromptSubmit` + `PreToolUse(כל כלי)` | `PreToolUse(reply)` + `Stop` |
| מי מייצר אותם | הסשן הראשי **וכל agent רקע** | **רק** הסשן הראשי |
| async | true | `Stop` = true (!) |

`PreToolUse` בלי matcher נורה על **כל** קריאת כלי של **כל** agent. `Stop` נורה רק בסוף התור של הסשן הראשי. `SubagentStop` לא מוגדר. לכן:

> ל-worker רקע יש את היכולת להדליק את מחוון ההקלדה, ואין לו שום יכולת לכבות אותו.

זו לא באג בקוד של סקריפט מסוים — זו טופולוגיה שבה **אין בעלים אחד למחוון**.

### שלושה מנגנוני כשל עצמאיים שנובעים ממנה

**1. worker רקע מדליק ולא מכבה (המנגנון הראשי, זה של היום).**
worker שולח reply → `PostToolUse(reply)` דורך flag → הקריאה הבאה שלו לכלי → `RESUME-FIRE` → לולאת `session` עולה → ה-worker מסיים → `SubagentStop` לא קיים → **אף אחד לא עוצר**. רץ עד ה-cap (30 דק').

**2. מרוץ אבוד בין tick ל-Stop (גם בסשן הראשי).**
שניהם `async: true`, ואין ביניהם סדר מובטח. `typing_session_tick` → `start_typing.py` → Popen **detached** של `typing_loop.py`, ו-`typing_loop.py` כותב את ה-PID של עצמו לקובץ (שורות 68-72) **אחרי** שהוא עולה. אם `stop_typing.py` (מ-`Stop`) רץ בחלון שבין ה-spawn לכתיבת ה-PID — הוא קורא את קובץ ה-PID **הישן**, קוטל PID מת, מוחק את הקובץ; ואז הלולאה החדשה כותבת את הקובץ מחדש עם ה-PID שלה. **הלולאה החדשה נולדה יתומה**. חלון של מאות מילישניות, בכל תור.

**3. שתי מערכות typing מקבילות שעיוורות זו לזו.**
- `typing_pid_{ORIGINAL_MSG_ID}.txt` — משמעת agents (תחקור #016).
- `typing_pid_session.txt` — hooks.

`stop_typing.py 13438` לא נוגע ב-session. `typing_session_stop.py` לא נוגע ב-13438. לטלגרם אין API של "הפסק להקליד" — המחוון הוא **האיחוד** של הלולאות. מספיק ששורדת אחת מהן כדי שעומר יראה "מקליד". כל תיקון שנוגע במערכת אחת בלבד לא יכול לפתור את הבעיה.

## פתרון מוצע

### העיקרון

**המחוון הופך מ"תהליך שצריך לקטול" ל"חוזה שכירות (lease) שצריך לחדש".**

היפוך שליטה: `PreToolUse(כל כלי)` — שכבר נורה מכל agent, ראשי או רקע — יהיה **מחדש-החוזה**, לא **המפעיל**. הלולאה מתה מעצמה כשמפסיקים לחדש. כשעבודה נעצרת מכל סיבה שהיא (סוף תור, worker שסיים, agent שקרס, קומפקט, קריסת הסשן) — אין יותר קריאות כלי, אין חידוש, הלולאה מתה תוך ~15 שניות. **בלי `Stop`, בלי `SubagentStop`, בלי מרוץ.**

זה לא "עוד מקום שקורא stop_typing". זה מוחק את המחלקה: הגבול העליון של typing יתום הופך מ-30 דקות ל-15 שניות, ולא בגלל שמישהו זכר לעצור.

**גילוי נאות (מה זה לא פותר):** מקרה שבו הדיספאצ'ר מריץ קריאות כלי (ניקוי, מחיקת ACK, action_log) **אחרי** ה-reply הסופי — יגרום להבהוב של כמה שניות. שינוי 6 מטפל בכך בכלל סדר, וה-lease חוסם את זה ב-15 שניות במקרה הגרוע. זה הבדל של סדר גודל, לא פתרון מושלם.

### שינוי 4: קובץ חדש `scripts/typing_lease.py` — הבעלים היחיד של המחוון

```python
#!/usr/bin/env python
"""Single owner of the Telegram typing indicator (investigation #043).

The indicator is a LEASE, not a process someone must remember to kill:
  open_lease(chat_id)  - only on an incoming user message (UserPromptSubmit)
  renew()              - on every tool call, from ANY agent (PreToolUse)
  pause()              - before every reply (PreToolUse reply): deadline=0
  close()              - at turn end (Stop): remove the lease entirely

If renewals stop for ANY reason - turn ended, background worker finished,
agent crashed, session compacted, async race - the loop dies within
LEASE_SECONDS. No Stop hook, no SubagentStop hook and no ordering guarantee
is required for correctness.
"""
import os, sys, json, time, subprocess

LEASE_FILE = "D:/Kai/tmp/typing_lease.json"
PID_FILE = "D:/Kai/tmp/typing_pid_session.txt"
TYPING_LOOP = os.path.join(os.path.dirname(os.path.abspath(__file__)), "typing_loop.py")
LEASE_SECONDS = 15
DETACHED_PROCESS = 0x00000008
CREATE_NEW_PROCESS_GROUP = 0x00000200
CREATE_NO_WINDOW = 0x08000000


def _read():
    try:
        with open(LEASE_FILE, encoding="utf-8") as f:
            return json.load(f)
    except Exception:
        return None


def _write(lease):
    tmp = LEASE_FILE + ".tmp"
    with open(tmp, "w", encoding="utf-8") as f:
        json.dump(lease, f)
    os.replace(tmp, LEASE_FILE)   # atomic - no half-written lease is ever read


def _alive(pid):
    try:
        import psutil
        return psutil.pid_exists(int(pid))
    except Exception:
        return False


def _ensure_loop(lease):
    """Spawn a loop only if none is alive. Writes the pid INTO the lease first,
    so the loop can never be born orphaned (root cause #2 of investigation #043)."""
    if lease.get("pid") and _alive(lease["pid"]):
        return lease
    proc = subprocess.Popen(
        [sys.executable, TYPING_LOOP, str(lease["chat_id"]), PID_FILE, "0"],
        creationflags=DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW,
        close_fds=True, stdin=subprocess.DEVNULL,
        stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
    )
    lease["pid"] = proc.pid
    return lease


def open_lease(chat_id):
    lease = {"chat_id": str(chat_id), "deadline": time.time() + LEASE_SECONDS,
             "turn_open": True, "pid": 0}
    lease = _ensure_loop(lease)
    _write(lease)


def renew():
    """Extend an OPEN lease. Never creates one - a tool call alone must not be
    able to switch the indicator on."""
    lease = _read()
    if not lease or not lease.get("turn_open"):
        return
    lease["deadline"] = time.time() + LEASE_SECONDS
    lease = _ensure_loop(lease)
    _write(lease)


def pause():
    """Before a reply: stop typing now, but keep the turn open so continued work
    brings it straight back with no dead gap."""
    lease = _read()
    if not lease:
        return
    lease["deadline"] = 0
    _write(lease)


def close():
    """Turn end. Best-effort only - lease expiry already bounds everything."""
    for path in (LEASE_FILE, "D:/Kai/tmp/typing_resume_armed.json"):
        try:
            os.remove(path)
        except Exception:
            pass


if __name__ == "__main__":
    cmd = sys.argv[1] if len(sys.argv) > 1 else ""
    if cmd == "open" and len(sys.argv) > 2:
        open_lease(sys.argv[2])
    elif cmd == "renew":
        renew()
    elif cmd == "pause":
        pause()
    elif cmd == "close":
        close()
```

**סיבה:** כל ההיגיון במקום אחד, עם ארבע פעולות ברורות. `_ensure_loop` כותב את ה-PID **ל-lease לפני** ה-`_write`, ולכן הכשל "לולאה שנולדה אחרי שה-stop כבר רץ" נסגר — הלולאה החדשה ממילא תמות תוך שנייה אם ה-lease לא קיים או פג.

### שינוי 6: `scripts/typing_session_stop.py` — שני מצבים: pause ו-close

**לפני (שורות 32-54, כל גוף `main`):**
```python
def main():
    try:
        os.remove(FLAG_FILE)
    except Exception:
        pass
    try:
        subprocess.run(
            [sys.executable, STOP_TYPING, SESSION_KEY],
            creationflags=CREATE_NO_WINDOW,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            timeout=10,
        )
        _tlog("STOP")
    except Exception as e:
        _tlog("stop-FAIL", repr(e))
```

**אחרי:**
```python
def main():
    sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
    from typing_lease import pause, close
    if "--end-turn" in sys.argv:
        close()          # Stop hook: turn over, drop the lease entirely
        _tlog("LEASE-CLOSE")
    else:
        pause()          # PreToolUse(reply): typing off now, turn stays open
        _tlog("LEASE-PAUSE")
```

**סיבה:** ההבחנה בין "הפסק להקליד כי אני שולח הודעה" לבין "התור נגמר" נעשית מפורשת. שניהם best-effort — ה-lease כבר תוחם את הכל.

### שינוי 8: ביטול המערכת השנייה — `typing_pid_{ORIGINAL_MSG_ID}`

זה החלק שמסיים את הדואליות שנוצרה ב-#016 ↔ `typing_add_resume`.

**המחוון של טלגרם הוא לכל צ׳אט, לא לכל הודעה.** כל הלולאות שולחות בדיוק את אותו `sendChatAction` לאותו `chat_id` — ההפרדה per-message מעולם לא נתנה שום דבר, רק אפשרה לשתי מערכות לשרוד זו את ה-stop של זו.

להסיר את הקריאות ל-`start_typing.py` / `stop_typing.py`:

| קובץ | מה להסיר |
|------|----------|
| `scripts/fast/_base.py` | `start_typing()` / `stop_typing()` → הופכים ל-no-op (להשאיר את החתימות כדי לא לשבור 23 קוראים) |
| `agents/listener.md` | Step −2 (`start_typing.py … {ORIGINAL_MSG_ID}`) וכל קריאות `stop_typing.py` |
| `agents/worker.md` | סעיף Typing indicator |
| `agents/investigation.md` | סעיף Typing indicator |
| `CLAUDE.md` → Common Patterns | ה-bullet של "Typing indicator" |

**טקסט חלופי ל-CLAUDE.md → Common Patterns:**

**לפני:**
```markdown
- **Typing indicator**: Always pass `ORIGINAL_MSG_ID` as the 2nd arg to `start_typing.py` / `stop_typing.py`. ORIGINAL_MSG_ID is the single typing key for an entire message lifetime — dispatcher, fast scripts, and workers all use it. Using ACK_MSG_ID instead causes orphan typing loops (see investigation #016).
```

**אחרי:**
```markdown
- **Typing indicator — agents must NEVER touch it.** The indicator is owned entirely by the hooks in `.claude/settings.json` via `scripts/typing_lease.py`. It is a 15-second lease renewed by every tool call from every agent (main or background), and it dies on its own when tool activity stops. Do NOT call `start_typing.py` or `stop_typing.py` from a dispatcher, worker, fast script or investigation — every historic stuck-typing bug (#015, #016, #043) came from an agent managing the indicator by hand.
```

**וכלל סדר חדש ל-`agents/listener.md`:**
```markdown
> **Final reply must be the LAST tool call of the turn.** Do all cleanup (delete ACK, remove temp files, action_log insert) BEFORE the final reply, never after. A tool call after the final reply renews the typing lease and shows "typing…" for a few seconds after Omer already has his answer.
```

**סיבה:** בעל אחד, מפתח אחד, תנאי יציאה אחד. אין יותר "מי אחראי על הלולאה הזו".

## בדיקה ידנית אחרי ההחלה

1. הודעה פשוטה ("מה התזכורות שלי?") — typing נדלק מיד, נכבה עם התשובה, ולא חוזר.
2. הודעה שמפעילה worker רקע — typing רציף לאורך העבודה, **ונעלם תוך ≤15 שניות אחרי שה-worker סיים** גם אם ה-`Stop` לא ירה.
3. עבודה ארוכה (>30 דקות) — המחוון **לא** נעלם באמצע (ה-cap הוסר).
4. אחרי כל בדיקה: `tasklist | grep python` — אין `typing_loop.py` שורד; `D:/Kai/tmp/` — אין `typing_lease.json` ואין `typing_pid_*.txt`.
5. ניסוי הרגרסיה של התחקור הזה: קריאת כלי מ-subagent בזמן שאין lease פתוח → **אסור** שתופיע לולאת typing.
